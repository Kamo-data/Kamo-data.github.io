Watt'sUp — Suivi conso électricité

Watt’sUp est un projet data construit à partir d’exports réels Engie. L’objectif est de transformer des fichiers bruts en données fiables et exploitables : ingestion Python, stockage PostgreSQL, modélisation dbt, contrôles de qualité et restitution dans Metabase.

GitHub : repo Watt'sUp Auteur : David Limoisin

Ce que fait le projet

Le pipeline prend en charge plusieurs types d’exports énergétiques et les aligne dans un modèle analytique cohérent. L’ensemble permet d’analyser la consommation sur plusieurs angles : volume global, saisonnalité, profil horaire, différence semaine / week-end et pics de puissance.

Périmètre fonctionnel

  • ingestion d’exports Engie mensuels
  • ingestion d’exports Engie horaires
  • ingestion des puissances max journalières et mensuelles
  • normalisation des données en staging
  • construction de tables analytiques en marts
  • tests sur la qualité, les périodes et les valeurs attendues
  • dashboards Metabase pour l’analyse et l’exploration

Architecture

Le projet suit une logique simple et reproductible :

  • fichiers source CSV / XLSX
  • ingestion Python vers des tables raw
  • transformation avec dbt
  • tests automatiques
  • visualisation dans Metabase

Ce que le projet démontre

  • capacité à structurer une mini-stack data complète
  • gestion de fichiers réels hétérogènes
  • séparation claire raw / staging / marts
  • mise en place de tests de qualité
  • restitution orientée usage métier
