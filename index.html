Watt'sUp — Suivi conso électricité

Watt’sUp est un projet portfolio complet construit à partir d’exports réels Engie. J’y ai mis en place un pipeline local reproductible : ingestion Python, stockage dans PostgreSQL, transformation avec dbt, tests de qualité, puis restitution dans Metabase.

Pourquoi ce projet est utile dans mon portfolio

Watt’sUp montre ma capacité à partir d’un besoin concret, à structurer la donnée, à produire des tables analytiques fiables et à les restituer dans des dashboards simples à lire. C’est un projet représentatif d’un positionnement Data Engineer / SQL / BI.
